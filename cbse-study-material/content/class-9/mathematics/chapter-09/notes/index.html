Propositions and their Converses

Mathematics asks us to do more than calculate: it asks us to decide whether a claim is true and explain why. Learn to read an if-then statement, form its converse, and use a proof or a counterexample to test each direction.

Learning goals

  • Recognise a mathematical proposition and state its truth value.
  • Identify the condition and conclusion in an if-then statement.
  • Write and test a converse without assuming it is true.
  • Use a proof for a true general claim and a counterexample for a false one.
  • Reason with number patterns and with the Baudhāyana–Pythagoras theorem and its converse.

1. Propositions and truth values

Definition

A proposition is a statement that has one definite truth value: it is true or it is false.

SentenceProposition?Reason / truth value
5 + 3 = 8YesTrue
9 is a prime numberYesFalse: 9 = 3 × 3
Every square is a rectangleYesTrue
What is your name?NoA question has no truth value
Close the door.NoA command has no truth value
x + 5 = 10Not by itselfIts truth depends on the value of x

A false proposition is still a proposition. The sentence “12 is odd” is false, but it is a complete claim with a definite truth value. A question, request, command, opinion, or open sentence with an unspecified variable is not a proposition by itself.

Make an open sentence definite

“x + 5 = 10” depends on x. If we specify x = 5, the resulting statement is true. If we specify x = 2, it is false. Giving a value makes the claim testable.

2. The if-then form: condition and conclusion

A conditional proposition has the form If P, then Q. P is the condition (or hypothesis); Q is the conclusion. The statement claims that whenever P holds, Q follows.

Read the direction carefully

Claim: If an integer is divisible by 4, then it is even.

Condition P: The integer is divisible by 4.

Conclusion Q: The integer is even.

Reason: An integer divisible by 4 is 4k for some integer k; 4k = 2(2k), so it is even.

Other wordings can express the same direction. “Q whenever P” means “If P, then Q.” “Q if P” also means “If P, then Q.” For example, “A number is even whenever it is divisible by 4” has the condition “divisible by 4” and conclusion “even.”

Watch the word order

In “Q if P,” the word if introduces P. Do not decide the direction by looking only at which phrase comes first.

3. The converse of a proposition

For a proposition “If P, then Q,” its converse is “If Q, then P.” To form it, swap the condition and conclusion while keeping the same objects and setting.

Original: P → Q

If an integer is divisible by 4, then it is even.

Converse: Q → P

If an integer is even, then it is divisible by 4.

The original is true. The converse is false: 6 is even, but 6 is not divisible by 4. The same number system and domain must be kept when comparing a proposition with its converse.

Four possible truth outcomes

OriginalConverseExample
TrueTrueIf an integer is divisible by 10, it ends in 0; and if it ends in 0, it is divisible by 10.
TrueFalseIf an integer is divisible by 6, it is divisible by 3; the converse fails for 3.
FalseTrueIf an integer is 3, its square is 9 (true); reversed: if its square is 9, it must be 3 (false, since −3 also works). Read the actual direction: the original “n²=9 implies n=3” is false; its converse is true.
FalseFalseIf an integer is prime, it is odd; and if it is odd, it is prime. Both fail (2 and 9).

For the third row, the original is “If n² = 9, then n = 3,” and the converse is “If n = 3, then n² = 9.”

4. Counterexamples: one valid case can disprove “every”

Definition

A counterexample is a specific case that satisfies the condition of a claim but makes its conclusion false. One valid counterexample disproves a claim that says “every” or “always.”

  1. Check that the proposed case satisfies the condition.
  2. Check that it breaks the conclusion.
  3. State both checks clearly.
ClaimCounterexampleWhy it works
Every prime number is odd.22 is prime but is not odd.
Every rectangle is a square.A 6 cm by 4 cm rectangleIt is a rectangle and its adjacent sides are unequal.
Every even integer is divisible by 4.66 is even but has remainder 2 on division by 4.
The square of every integer is greater than the integer.11² = 1, not greater than 1.

Proof or counterexample?

To establish a claim for all permitted cases, give a general argument. To disprove a universal claim, one permitted counterexample is enough. Checking several examples can suggest a pattern, but it does not prove a statement for every integer.

5. Number patterns and paired factors

Multiples: a direction may hold only one way

If an integer is a multiple of 6, it is a multiple of 3, because 6k = 3(2k). The converse fails: 9 is a multiple of 3 but not of 6.

Perfect squares and an odd number of positive factors

Factors of a positive integer usually pair as (a, n/a). For a square, the middle pair is a repeated factor, such as (4, 4) for 16. That single unpaired middle factor makes the total number of positive factors odd.

12

(1,12), (2,6), (3,4)
6 factors: even

16

(1,16), (2,8), (4,4)
5 factors: odd

36

(1,36), (2,18), (3,12), (4,9), (6,6)
9 factors: odd

The converse also holds for positive integers: if a number has an odd number of positive factors, one factor must pair with itself at the middle, so n = a × a and n is a perfect square. This relies on pairing all positive factors around the square root.

A pattern is not a proof

For example, the numbers Fk = 22k + 1 for k = 0, 1, 2, 3, 4 are 3, 5, 17, 257, 65537, all prime. This finite list does not prove that every later term is prime. In fact, F5 = 232 + 1 = 4,294,967,297 = 641 × 6,700,417, so it is composite. A counterexample ends the “every term is prime” claim.

6. Geometry: test the converse, do not trust the sketch

Isosceles triangles

If two sides of a triangle are equal, then the angles opposite those sides are equal. The converse is also true: if two angles of a triangle are equal, then the opposite sides are equal. These are paired results for triangles; the converse needs its own justification.

Squares and rectangles

Square → rectangle: true. A square has four right angles, so it meets the definition of a rectangle.

Rectangle → square: false. A 6 by 4 rectangle has four right angles but does not have four equal sides.

The Baudhāyana–Pythagoras theorem and its converse

Theorem: In a right-angled triangle with legs a and b and hypotenuse c, a² + b² = c².

Converse: If the sides of a triangle satisfy a² + b² = c², where c is the longest side, then the angle opposite c is a right angle.

In the converse lab below, change a and b; the third side is computed from c = √(a² + b²). The canvas is decorative support—the proof is the argument below.

Text alternative: a right triangle has perpendicular legs a and b, with hypotenuse c opposite the right angle.

1
Take a triangle whose sides a, b, c satisfy a² + b² = c², with c the longest side.
2
Construct a right-angled triangle with perpendicular sides a and b. By the theorem, its hypotenuse d satisfies d² = a² + b².
3
Since a² + b² = c², we have d² = c². Both are positive lengths, so d = c.
4
The constructed right triangle and the original triangle have matching three side lengths a, b, c. By SSS congruence, they are congruent.
5
Corresponding angles are equal. The original angle opposite c equals the constructed right angle, so it is 90°.

Therefore, the original triangle is right-angled.

7. Thirty worked examples

Read each solution as a model: name the direction, test the claim, then justify it.

Example 1 — Is “7 is prime” a proposition?

Yes. It is a declarative mathematical statement and has a definite value. Its value is true because its only positive factors are 1 and 7.

Example 2 — Is “12 is odd” a proposition?

Yes. It is false: 12 is divisible by 2, so it is even. False does not mean “not a proposition.”

Example 3 — Is “What is 8 × 7?” a proposition?

No. It is a question, so it does not assert a claim that can be true or false.

Example 4 — Is “Draw a rectangle” a proposition?

No. It is a command, not a claim with a truth value.

Example 5 — Is x + 4 = 10 a proposition?

Not until the value or domain of x is fixed. With x = 6 it is true; with x = 2 it is false.

Example 6 — Identify P and Q: If n is divisible by 10, n is divisible by 5.

P: n is divisible by 10. Q: n is divisible by 5. The claim is true because 10k = 5(2k).

Example 7 — Rewrite “Multiples of 8 are even.”

If an integer is a multiple of 8, then it is even. The condition is “multiple of 8”; the conclusion is “even.”

Example 8 — Write the converse of “If n is divisible by 4, n is even.”

Swap condition and conclusion: If n is even, then n is divisible by 4.

Example 9 — Is the converse in Example 8 true?

No. 6 is even, but it is not divisible by 4. Thus 6 is a counterexample.

Example 10 — Test the converse of “If n is divisible by 6, it is divisible by 3.”

The converse is “If n is divisible by 3, it is divisible by 6.” It is false for n = 3.

Example 11 — Test “Every prime is odd” and its converse.

The original is false for 2. The converse “Every odd integer is prime” is false for 9 = 3 × 3.

Example 12 — Prove that the sum of two odd integers is even.

Write the odd integers as 2m + 1 and 2n + 1. Their sum is 2(m + n + 1), twice an integer, so it is even.

Example 13 — Test both directions for “divisible by 10” and “ends in 0.”

For base-ten integers, each direction is true: a number ending in 0 is 10k, and every 10k has final digit 0.

Example 14 — Test the converse of “If a triangle is equilateral, it is equiangular.”

The converse is also true. An equiangular triangle has equal angles; equal angles in a triangle have equal opposite sides, so all three sides are equal.

Example 15 — Equal sides and opposite angles.

If two sides of a triangle are equal, the angles opposite them are equal. Conversely, equal angles have equal opposite sides. These are the isosceles-triangle result and its converse.

Example 16 — Square and rectangle.

Every square is a rectangle because it has four right angles. The converse fails for any rectangle whose adjacent sides differ, such as 6 cm and 4 cm.

Example 17 — “Every rectangle is a square.”

False. A 6 cm by 4 cm rectangle is a rectangle, but its sides are not all equal.

Example 18 — “Every even integer is divisible by 4.”

False. 2 is even and not divisible by 4. (6 also works.)

Example 19 — “Every multiple of 15 is divisible by 3 and 5.”

True. If n = 15k, then n = 3(5k) and n = 5(3k), so it is divisible by both.

Example 20 — If x = 4, then x² = 16; test the converse over integers.

The original is true. The converse says x² = 16 implies x = 4, which is false for x = −4.

Example 21 — “If n² = 9, then n = 3.”

Over integers this is false because n = −3 also has square 9. Its converse, “If n = 3, then n² = 9,” is true.

Example 22 — Does x² = y² imply x = y?

No. Take x = 2 and y = −2: their squares are equal but x ≠ y. The converse is true: if x = y, then squaring both equal quantities gives x² = y².

Example 23 — Can checking 2, 4, 6, 8 prove “all even numbers are divisible by 4”?

No. Those examples do not cover every even integer, and 2 is already a counterexample. A finite sample cannot prove an unrestricted claim.

Example 24 — Prove the converse of Pythagoras.

Construct a right triangle with the same two shorter sides a and b. Its hypotenuse d has d² = a² + b² = c², so d = c. The triangles have the same three sides and are congruent by SSS. The given triangle therefore has a right angle opposite c.

Example 25 — Why does a square have an odd number of positive factors?

For n = r², factors below r pair with factors above r as (d, n/d). The middle factor r pairs with itself, leaving one unpaired factor, so the total is odd.

Example 26 — Why does an odd number of factors imply a square?

Non-square positive integers have no factor equal to their square root, so every factor pairs with a distinct partner and the count is even. An odd count therefore requires a middle factor r paired with itself: n = r².

Example 27 — Do five prime values prove every Fermat number is prime?

No. Testing k = 0 to 4 gives only five cases. At k = 5, 2³² + 1 = 641 × 6,700,417, a composite counterexample.

Example 28 — Read “A number is even if it is divisible by 6.”

“If it is divisible by 6, then it is even.” The condition is divisibility by 6; the conclusion is evenness.

Example 29 — Read “A number is divisible by 5 whenever it ends in 0.”

“Whenever” introduces the condition: if the number ends in 0, then it is divisible by 5. This claim is true in base ten.

Example 30 — Rain and a wet road.

“If it rains, the road gets wet” may be true in a stated situation. The converse “If the road is wet, then it rained” does not follow; a road-cleaning truck can make it wet without rain.

8. Quick reference and exam method

Proposition

A statement with a definite truth value: true or false.

Condition / hypothesis

The “if” part P in “If P, then Q.”

Conclusion

The “then” part Q in “If P, then Q.”

Converse

Swap P and Q: “If Q, then P.” Test it independently.

Counterexample

A valid case that meets the condition but breaks the conclusion.

Proof

A connected reason showing why a claim holds for every permitted case.

1
Rewrite the claim in if-then form.
2
Underline the condition and conclusion.
3
Swap them to write the converse.
4
Decide each truth value separately; prove true general claims and give a counterexample for false universal claims.

Common mistakes

  • Assuming a true proposition has a true converse.
  • Calling a false statement “not a proposition.”
  • Giving a number that fails the condition as a counterexample.
  • Using a few checked cases as a proof of “every.”
  • Reversing an “if” statement without swapping both parts.
  • Trusting a diagram’s appearance instead of its stated measurements.

11. One-minute revision

Remember

  • A proposition has a definite truth value.
  • “If P, then Q” and “If Q, then P” are different claims.
  • A proposition and its converse can have any of the four true/false combinations.
  • Use a general proof to establish a true claim for all cases.
  • One valid counterexample disproves a universal claim.
  • The converse of Pythagoras follows by constructing a right triangle and using SSS congruence.
