Exercise Set 8.1 · Explicit and recursive rules

Question 1 · First five terms from three explicit rules

Question: Find the first five terms for (i) tₙ = 3n − 4, (ii) tₙ = 2 − 5n, and (iii) tₙ = n² − 2n + 3, where n ≥ 1.

Method: Substitute n = 1, 2, 3, 4, 5 into each rule.

  1. (i) 3n − 4 gives −1, 2, 5, 8, 11.
  2. (ii) 2 − 5n gives −3, −8, −13, −18, −23.
  3. (iii) n² − 2n + 3 gives 2, 3, 6, 11, 18.

Answer: (i) −1, 2, 5, 8, 11; (ii) −3, −8, −13, −18, −23; (iii) 2, 3, 6, 11, 18.

Question 2 · Find the 10th and 15th terms

Question: Find the 10th and 15th terms of tₙ = 5n − 3, n ≥ 1.

  1. For n = 10: t₁₀ = 5(10) − 3 = 50 − 3 = 47.
  2. For n = 15: t₁₅ = 5(15) − 3 = 75 − 3 = 72.

Answer: t₁₀ = 47 and t₁₅ = 72.

Question 3 · Check whether two numbers are terms

Question: Decide whether 97 and 172 occur in the sequence tₙ = 5n − 3, n ≥ 1.

  1. Set 5n − 3 = 97. Then 5n = 100, so n = 20. This is a positive integer, so 97 is a term (the 20th).
  2. Set 5n − 3 = 172. Then 5n = 175, so n = 35. This is a positive integer, so 172 is a term (the 35th).

Answer: both are terms: 97 = t₂₀ and 172 = t₃₅.

Question 4 · Find the position of 607

Question: Which term of the sequence tₙ = 5n − 3 is 607?

  1. Set tₙ = 607: 5n − 3 = 607.
  2. Add 3: 5n = 610.
  3. Divide by 5: n = 122.

Answer: 607 is the 122nd term.

Question 5 · Build a recursive sequence and test membership

Question: A sequence starts at t₁ = −5 and adds 3 each time. Find its first five terms and determine whether 52 occurs, and if so, its position.

  1. Generate terms: t₁ = −5; t₂ = −5 + 3 = −2; t₃ = −2 + 3 = 1; t₄ = 1 + 3 = 4; t₅ = 4 + 3 = 7.
  2. The sequence is an AP with first term −5 and difference 3, so tₙ = −5 + 3(n − 1).
  3. Set this equal to 52: −5 + 3(n − 1) = 52, so 3(n − 1) = 57, n − 1 = 19, n = 20.

Answer: first five terms are −5, −2, 1, 4, 7; 52 is a term, at position 20.

Question 6 · Recurrence using three previous terms

Question: Given T₁ = 1, T₂ = 2, T₃ = 4 and Tₙ = Tₙ₋₁ + Tₙ₋₂ + Tₙ₋₃ for n ≥ 4, find T₄ through T₈.

  1. T₄ = T₃ + T₂ + T₁ = 4 + 2 + 1 = 7.
  2. T₅ = T₄ + T₃ + T₂ = 7 + 4 + 2 = 13.
  3. T₆ = T₅ + T₄ + T₃ = 13 + 7 + 4 = 24.
  4. T₇ = T₆ + T₅ + T₄ = 24 + 13 + 7 = 44.
  5. T₈ = T₇ + T₆ + T₅ = 44 + 24 + 13 = 81.

Answer: T₄ = 7, T₅ = 13, T₆ = 24, T₇ = 44, T₈ = 81.

Exercise Set 8.2 · Arithmetic progressions

Question 1 · Terms of an AP

Question: Find the 10th and 26th terms of 3, 8, 13, 18, …

  1. The first term is a = 3 and common difference d = 8 − 3 = 5.
  2. Use tₙ = a + (n − 1)d. Then t₁₀ = 3 + 9(5) = 48.
  3. Similarly, t₂₆ = 3 + 25(5) = 128.

Answer: t₁₀ = 48 and t₂₆ = 128.

Question 2 · Find positions in a decreasing AP

Question: In 21, 18, 15, … find the term equal to −81 and check whether 0 is also a term.

  1. Here a = 21, d = −3, so tₙ = 21 − 3(n − 1).
  2. For −81: 21 − 3(n − 1) = −81, giving n − 1 = 34 and n = 35.
  3. For 0: 21 − 3(n − 1) = 0, giving n − 1 = 7 and n = 8.

Answer: −81 is the 35th term; 0 is the 8th term.

Question 3 · Explicit and recursive AP rules

Question: For 11, 8, 5, 2, … find the nth-term rule and a recursive rule.

  1. The common difference is d = 8 − 11 = −3.
  2. Explicit rule: tₙ = 11 + (n − 1)(−3) = 14 − 3n.
  3. Recursive rule: start at t₁ = 11 and subtract 3 each time.

Answer: tₙ = 14 − 3n; t₁ = 11 and tₙ = tₙ₋₁ − 3 for n ≥ 2.

Question 4 · A 50-term AP

Question: An AP has 50 terms, its third term is 12 and its last term is 106. Find the 29th term.

  1. Let its first term be a and common difference be d. Then a + 2d = 12 and a + 49d = 106.
  2. Subtract: 47d = 94, so d = 2. Substitute to get a + 4 = 12, hence a = 8.
  3. t₂₉ = a + 28d = 8 + 28(2) = 64.

Answer: the 29th term is 64.

Question 5 · Count and sum two-digit multiples of 3

Question: How many two-digit numbers are divisible by 3, and what is their sum?

  1. The sequence is 12, 15, 18, …, 99, with a = 12, d = 3 and last term l = 99.
  2. Find the number of terms: 99 = 12 + (n − 1)3, so n = 30.
  3. Sum them: S₃₀ = (30/2)(12 + 99) = 15 × 111 = 1,665.

Answer: 30 numbers; their sum is 1,665.

Question 6 · Annual salary increments

Question: A starting annual salary of ₹5,00,000 increases by ₹20,000 each year. After how many years does it reach ₹7,00,000?

  1. Salaries form an AP with first-year salary a = ₹5,00,000 and d = ₹20,000.
  2. Set a + (n − 1)d = ₹7,00,000. Thus (n − 1) × ₹20,000 = ₹2,00,000, so n − 1 = 10 and n = 11.
  3. The target is the 11th year's salary, which is 10 years after the first year.

Answer: after 10 years (the ₹7,00,000 salary is in year 11).

Question 7 · Marbles in triangular rows

Question: Rows contain 1, 2, 3, …, 25 marbles. Find the total number used.

  1. This is an AP with 25 terms, first term 1 and last term 25.
  2. S₂₅ = (25/2)(1 + 25) = (25/2)(26) = 25 × 13.

Answer: 325 marbles.

Exercise Set 8.3 · Geometric progressions

Question 1 · Find an unknown first term, then a later GP term

Question: A GP has common ratio 2 and 8th term 192. Find its 12th term.

  1. Use tₙ = arⁿ⁻¹. From t₈ = a(2⁷) = 192, a = 192/128 = 3/2.
  2. Then t₁₂ = (3/2)(2¹¹) = 3 × 2¹⁰ = 3,072.

Answer: t₁₂ = 3,072.

Question 2 · Explicit rule for a GP

Question: For 5, 25, 125, … find the 10th term and the general nth term.

  1. First term a = 5; common ratio r = 25/5 = 5.
  2. tₙ = arⁿ⁻¹ = 5 × 5ⁿ⁻¹ = 5ⁿ.
  3. Therefore t₁₀ = 5¹⁰ = 9,765,625.

Answer: t₁₀ = 9,765,625; tₙ = 5ⁿ.

Question 3 · Turn a recursive rule into an explicit one

Question: A sequence starts at t₁ = 2 and follows tₙ₊₁ = 3tₙ − 2. Which term is 730?

  1. Subtract 1: tₙ₊₁ − 1 = 3(tₙ − 1). Let uₙ = tₙ − 1; then uₙ₊₁ = 3uₙ and u₁ = 1.
  2. Thus uₙ = 3ⁿ⁻¹ and tₙ = 3ⁿ⁻¹ + 1.
  3. Set 3ⁿ⁻¹ + 1 = 730. Since 729 = 3⁶, n − 1 = 6 and n = 7.

Answer: 730 is the 7th term.

Question 4 · Find the position and rules of a GP

Question: In 2, 6, 18, … find the term equal to 4,374 and give explicit and recursive rules.

  1. a = 2 and r = 3. Solve 2 × 3ⁿ⁻¹ = 4,374, so 3ⁿ⁻¹ = 2,187 = 3⁷ and n = 8.
  2. Explicit rule: tₙ = 2 × 3ⁿ⁻¹.
  3. Recursive rule: t₁ = 2; multiply each term by 3.

Answer: 4,374 is the 8th term; tₙ = 2 × 3ⁿ⁻¹; t₁ = 2 and tₙ = 3tₙ₋₁ for n ≥ 2.

Question 5 · Bouncing ball

Question: A ball is dropped from 80 m and rebounds to 60% of the previous drop height. Find the 5th rebound height and total vertical distance by its 6th ground contact.

  1. The first rebound is 80 × 0.6 = 48 m. Rebound heights form a GP with a = 48 and r = 0.6.
  2. Fifth rebound: t₅ = 48(0.6)⁴ = 6.2208 m.
  3. The first five rebound heights sum to 48 + 28.8 + 17.28 + 10.368 + 6.2208 = 110.6688 m.
  4. By the 6th ground contact, the initial 80 m fall has occurred, and each rebound height has been travelled up and down: distance = 80 + 2(110.6688) = 301.3376 m.

Answer: 5th rebound = 6.2208 m; total distance = 301.3376 m.

Question 6 · Position of 128 in a radical-ratio GP

Question: Which term of 2, 2√2, 4, … is 128?

  1. The first term is 2 and each term is multiplied by √2.
  2. Set 2(√2)ⁿ⁻¹ = 128, so (√2)ⁿ⁻¹ = 64 = (√2)¹².
  3. Therefore n − 1 = 12 and n = 13.

Answer: 128 is the 13th term.

Question 7 · Sierpiński square carpet

Question: At each stage, divide every shaded square into a 3 × 3 grid and remove its centre. Find shaded-square counts and the retained area through Stage 5, write explicit and recursive rules, and state the limiting area.

  1. Stage 0 has 1 shaded square; each stage keeps 8 copies of every shaded square. Counts for Stages 0–5 are 1, 8, 64, 512, 4,096, 32,768.
  2. If Cₙ is the count at Stage n, then C₀ = 1 and Cₙ = 8Cₙ₋₁. Hence Cₙ = 8ⁿ.
  3. Each step retains 8/9 of the preceding area. With initial area 1, areas at Stages 1–5 are 8/9, 64/81, 512/729, 4,096/6,561 and 32,768/59,049.
  4. If A₀ = 1, then Aₙ = (8/9)Aₙ₋₁ and explicitly Aₙ = (8/9)ⁿ. Since 0 < 8/9 < 1, this area approaches 0 as n grows.

Answer: Cₙ = 8ⁿ; Aₙ = (8/9)ⁿ; the retained area tends to 0.

End-of-Chapter Exercises

Question 1 · Find a later term from two AP terms

Question: An AP has 11th term 38 and 16th term 73. Find its 31st term.

  1. Let first term be a and difference d. Then a + 10d = 38 and a + 15d = 73.
  2. Subtract: 5d = 35, so d = 7. Then a + 70 = 38, giving a = −32.
  3. t₃₁ = a + 30d = −32 + 210 = 178.

Answer: t₃₁ = 178.

Question 2 · Determine an AP

Question: Find the AP whose third term is 16 and whose seventh term exceeds its fifth term by 12.

  1. Let the first term be a and common difference d. From t₃ = 16, a + 2d = 16.
  2. t₇ − t₅ = (a + 6d) − (a + 4d) = 2d = 12, so d = 6.
  3. a + 12 = 16, so a = 4.

Answer: 4, 10, 16, 22, …

Question 3 · Three-digit multiples of 7

Question: How many three-digit numbers are divisible by 7?

  1. The first is 105 = 7 × 15; the last is 994 = 7 × 142.
  2. These form an AP with a = 105, d = 7 and last term 994.
  3. 994 = 105 + (n − 1)7, so n − 1 = 127 and n = 128.

Answer: 128 numbers.

Question 4 · Multiples of 4 in an interval

Question: How many multiples of 4 lie between 10 and 250?

  1. The first qualifying multiple is 12 and the last is 248; common difference is 4.
  2. 248 = 12 + (n − 1)4, so n − 1 = 59 and n = 60.

Answer: 60 multiples.

Question 5 · Find GPs from two conditions

Question: Find all GPs whose first two terms sum to −4 and whose fifth term is four times the third.

  1. Let the first term be a and ratio r. Conditions give a(1 + r) = −4 and ar⁴ = 4ar², so r² = 4.
  2. If r = 2, then 3a = −4, so a = −4/3. This gives −4/3, −8/3, −16/3, …
  3. If r = −2, then −a = −4, so a = 4. This gives 4, −8, 16, …

Answer: either −4/3, −8/3, −16/3, … or 4, −8, 16, …

Question 6 · Consecutive natural-number sums

Question: Express 100 as a sum of consecutive natural numbers in every possible way.

  1. For n consecutive numbers beginning with a, 100 = n(2a + n − 1)/2, so 2a = 200/n − n + 1.
  2. Check positive integer lengths n that divide 200 and make a a positive integer. The qualifying lengths are n = 1, 5 and 8.
  3. These give a = 100, a = 18 and a = 9 respectively.

Answer: 100; 18 + 19 + 20 + 21 + 22; and 9 + 10 + 11 + 12 + 13 + 14 + 15 + 16.

Question 7 · Bacteria doubling

Question: A culture starts with 30 bacteria and doubles hourly. Find the counts at the end of hours 2 and 4, and at the end of hour n.

  1. At hour 0 there are 30; after one hour there are 60. Thus the sequence indexed by completed hours is 60, 120, 240, … with a = 60 and r = 2.
  2. Hour 2: 60 × 2 = 120. Hour 4: 60 × 2³ = 480.
  3. At hour n: 60 × 2ⁿ⁻¹ = 30 × 2ⁿ.

Answer: 120, 480 and 30 × 2ⁿ bacteria.

Question 8 · Recover the first terms of an AP

Question: The 4th and 8th terms of an AP sum to 24, while the 6th and 10th terms sum to 44. Find its first three terms.

  1. Let first term be a and difference d. Then 2a + 10d = 24, so a + 5d = 12.
  2. Also 2a + 14d = 44, so a + 7d = 22. Subtracting gives 2d = 10, hence d = 5.
  3. a + 25 = 12, so a = −13. The first three terms are a, a + d, a + 2d.

Answer: −13, −8, −3.

Question 9 · Sum of natural numbers above 1,000

Question: Find the smallest n for which 1 + 2 + … + n is greater than 1,000.

  1. Use Sₙ = n(n + 1)/2. We need n(n + 1) > 2,000.
  2. For n = 44, S₄₄ = 44 × 45/2 = 990, which is not enough.
  3. For n = 45, S₄₅ = 45 × 46/2 = 1,035, which exceeds 1,000.

Answer: n = 45.

Question 10 · Position and rules in a GP

Question: For 2, 8, 32, … find the term equal to 131,072 and give explicit and recursive rules.

  1. a = 2 and r = 4. Set 2 × 4ⁿ⁻¹ = 131,072, giving 4ⁿ⁻¹ = 65,536 = 4⁸.
  2. Thus n − 1 = 8 and n = 9.
  3. The explicit rule is tₙ = 2 × 4ⁿ⁻¹. The recursive rule starts at t₁ = 2 and multiplies by 4.

Answer: 131,072 is the 9th term; tₙ = 2 × 4ⁿ⁻¹; t₁ = 2 and tₙ = 4tₙ₋₁ for n ≥ 2.

Question 11 · First three terms from sum and product

Question: Three consecutive terms of a GP sum to 13/12 and have product −1. Find the common ratio and the terms.

  1. Write the terms as a/r, a, ar. Their product is a³ = −1, so a = −1.
  2. Use the sum: −1/r − 1 − r = 13/12. Multiplying by 12r gives 12r² + 25r + 12 = 0.
  3. Factor: (4r + 3)(3r + 4) = 0. Thus r = −3/4 or r = −4/3.
  4. For r = −3/4 the terms are 4/3, −1, 3/4. For r = −4/3 they are 3/4, −1, 4/3.

Answer: r = −3/4 with terms 4/3, −1, 3/4; or r = −4/3 with terms 3/4, −1, 4/3.

Question 12 · Prove selected terms form a GP

Question: If the 4th, 10th and 16th terms of a GP are x, y and z, prove x, y and z are in GP.

  1. For first term a and ratio r: x = ar³, y = ar⁹ and z = ar¹⁵.
  2. Then y/x = r⁶ and z/y = r⁶, so consecutive ratios agree.
  3. Equivalently, y² = (ar⁹)² = (ar³)(ar¹⁵) = xz, the condition for three terms to be in GP.

Answer: x, y and z form a GP with common ratio r⁶.

Question 13 · GP from sum and sum of squares

Question: Three terms of a GP sum to 26 and their squares sum to 364. Find the terms.

  1. Write the terms as x, y, z with y² = xz. Given x + y + z = 26 and x² + y² + z² = 364.
  2. (x + y + z)² = 676 = 364 + 2(xy + yz + xz), so xy + yz + xz = 156.
  3. Since xz = y², this becomes y(x + z) + y² = y(26 − y) + y² = 26y = 156. Hence y = 6.
  4. Then x + z = 20 and xz = 36. The roots are 2 and 18.

Answer: 2, 6, 18 or 18, 6, 2.

Question 14 · Recursively defined cumulative sequence

Question: Let P₁ = 1, P₂ = 2 and Pₙ = P₁ + P₂ + … + Pₙ₋₁ + 1 for n > 2. Find P₁ through P₈, then give simpler recursive and explicit rules.

  1. Apply the rule: P₃ = 1 + 2 + 1 = 4; P₄ = 1 + 2 + 4 + 1 = 8. Continuing gives P₅ = 16, P₆ = 32, P₇ = 64, P₈ = 128.
  2. Each new term is twice the previous one, so P₁ = 1 and Pₙ = 2Pₙ₋₁ for n ≥ 2.
  3. This is a GP with first term 1 and ratio 2, hence Pₙ = 2ⁿ⁻¹.

Answer: 1, 2, 4, 8, 16, 32, 64, 128; recursive Pₙ = 2Pₙ₋₁; explicit Pₙ = 2ⁿ⁻¹.

Question 15 · A sum-defined Virahānka–Fibonacci sequence

Question: Let W₁ = 1, W₂ = 2 and Wₙ = W₁ + W₂ + … + Wₙ₋₂ + 2 for n > 2. Find W₁ through W₈ and identify the sequence.

  1. Use the given rule: W₃ = 1 + 2 = 3; W₄ = 1 + 2 + 2 = 5; W₅ = 1 + 2 + 3 + 2 = 8.
  2. Continuing gives W₆ = 13, W₇ = 21 and W₈ = 34.
  3. Subtract successive defining sums: Wₙ − Wₙ₋₁ = Wₙ₋₂, so Wₙ = Wₙ₋₁ + Wₙ₋₂ for n ≥ 3.

Answer: 1, 2, 3, 5, 8, 13, 21, 34; this is the Virahānka–Fibonacci sequence.
