GALLERY IMAGES
==============
Drop your photos into this folder with these exact filenames:

  classroom.png       — Interactive Classrooms
  achievements.jpg    — Student Achievements
  achievements-2.jpg  — More Achievements
  smart-learning.jpg  — Smart Learning
  group-discussion.jpg — Group Discussions
  workshops.jpg       — Workshops & Events
  graduation.jpg      — Graduation Day

Requirements:
- JPG or PNG format
- Recommended size: 800x600px or larger
- Keep file sizes under 500KB for fast loading

Once you add the images, just refresh the website — they'll show up automatically.
