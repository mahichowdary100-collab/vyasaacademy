Topic 1 – Linear Inequations

A. Learning Objectives

After studying this topic you should be able to:

  • Distinguish between a linear equation and a linear inequation (inequality).
  • Understand the replacement set and find the solution set of an inequation.
  • Apply the four rules for solving inequations, including reversing the sign when multiplying or dividing by a negative number.
  • Represent solution sets on the real number line using closed and open dots.
  • Solve a chain (compound) inequation such as \(a < bx + c \le d\).

B. Basic Concepts and Definitions

Inequation (inequality)

A statement that relates two algebraic expressions using one of the symbols \(\le\) (less than or equal to), \(\ge\) (greater than or equal to), < (less than) or > (greater than). Unlike an equation, it almost always has a set of solutions, not just one value.

Replacement set and solution set

The replacement set is the set from which the variable can be chosen – typically \(x \in \mathbb{W}\) (whole numbers), \(x \in \mathbb{N}\), \(x \in \mathbb{I}\) (integers) or \(x \in \mathbb{R}\) (real numbers). The solution set is the set of all values from the replacement set that actually satisfy the inequation.

Example: for \(2x + 4 \le 14\) with \(x \in \mathbb{W}\), the solution set is \(\{0, 1, 2, 3, 4, 5\}\). With \(x \in \mathbb{R}\) the same inequation has infinitely many solutions: \(x \le 5\).

Rules for solving inequations
  • The same number can be added to or subtracted from both sides.
  • Both sides can be multiplied or divided by the same positive number – the sign stays the same.
  • Both sides can be multiplied or divided by the same negative number – the sign must be reversed.

Also: you may not multiply or divide by zero, and you may not multiply or divide by an unknown whose sign you do not know.

Number-line representation

Use a closed (filled) dot for \(\le\) or \(\ge\) (the endpoint is included) and an open (hollow) dot for < or > (the endpoint is excluded). Shade the line in the direction of the solution set.

C. Important Formulas

Reversal rule (key!)
\(a < b \;\Rightarrow\; -a > -b\)
Multiplying (or dividing) both sides by a negative reverses the inequality; never forget this when the coefficient of \(x\) is made negative.
Solving a linear inequation
\(ax + b \le c \;\Rightarrow\; x \le \dfrac{c - b}{a} \;\text{(if } a > 0\text{)}\)
Isolate the variable exactly as in an equation, applying the reversal rule whenever you multiply or divide by a negative coefficient.
Chain (compound) inequation
\(a < bx + c \le d\)
Split into \(a < bx + c\) and \(bx + c \le d\), solve each, then take the common (AND) region.

D. Step-by-Step Solved Examples

Level 1 Inequation with whole-number replacement set

Example 1

Solve \(7x - 3 \ge 11\) where \(x \in \mathbb{W}\). Write down the solution set and show it on a number line.

Required: solution set of the inequation.

1
Add 3 to both sides: \(7x \ge 14\).
2
Divide by the positive number 7 (no sign change): \(x \ge 2\).
3
Since \(x \in \mathbb{W} = \{0, 1, 2, 3, \dots\}\), the solution set is \(\{2, 3, 4, \dots\}\).
4
On the number line place a closed dot at 2 and shade to the right.

Level 2 Real-number solution and half-open chain

Example 2

Solve \(-3 < 2x + 1 \le 9\) where \(x \in \mathbb{R}\). Represent the solution on the real number line.

1
Split into two parts: \(-3 < 2x + 1\) and \(2x + 1 \le 9\), then work both together.
2
Subtract 1 throughout: \(-4 < 2x \le 8\).
3
Divide throughout by \(2 > 0\): \(-2 < x \le 4\).
4
On the number line use an open dot at \(-2\) (strict) and a closed dot at 4, shading between them.

Level 3 Chain with a negative coefficient (verified ICSE board question)

Example 3 – ICSE 2023 (Section B)

Solve the inequation \(-5(x - 9) \ge 17 - 9x > x + 2, \; x \in \mathbb{R}\). Write down the solution set and represent it on the real number line.

1
Left part: \(-5(x - 9) \ge 17 - 9x\). Expand: \(-5x + 45 \ge 17 - 9x\).
2
Add \(9x\) to both sides: \(4x + 45 \ge 17\), so \(4x \ge -28\) and \(x \ge -7\).
3
Right part: \(17 - 9x > x + 2\). Add \(9x\): \(17 > 10x + 2\), so \(15 > 10x\) and \(x < \frac{3}{2}\).
4
Both must hold: \(-7 \le x < \frac{3}{2}\).
5
Solution set: \(\{x : x \in \mathbb{R},\; -7 \le x < \frac{3}{2}\}\). Number line: closed dot at \(-7\), open dot at \(\frac{3}{2}\), shade between.

E. Exam-Style Questions

Question E1 ICSE Board 2023

Solve the inequation \(2x + 4 \le 14\) where \(x \in \mathbb{W}\) (whole numbers). Write down the solution set.

Show answer

\(2x \le 10\) so \(x \le 5\). Solution set = \(\{0, 1, 2, 3, 4, 5\}\).

Question E2 Original

Solve \(3x + 2 \ge 2x + 9\) where \(x \in \mathbb{I}\) (integers).

Show answer

\(3x - 2x \ge 9 - 2\), so \(x \ge 7\). Solution set = \(\{7, 8, 9, \dots\}\).

Question E3 Original

Solve \(-2 \le 3x - 1 < 8\) where \(x \in \mathbb{R}\).

Show answer

Add 1: \(-1 \le 3x < 9\), divide by 3: \(-\frac{1}{3} \le x < 3\). Solution set = \(\{x : x \in \mathbb{R},\; -\frac{1}{3} \le x < 3\}\).

Question E4 Original

If \(x \in \mathbb{N}\), solve \(4x - 7 \le 13\) and state how many solutions there are.

Show answer

\(4x \le 20\) so \(x \le 5\). Since \(x \in \mathbb{N} = \{1, 2, 3, 4, 5\}\), the solution set is \(\{1, 2, 3, 4, 5\}\) – five solutions.

Question E5 Original

Solve \(\dfrac{2x - 1}{3} > 3\) for \(x \in \mathbb{R}\) and show the solution on a number line.

Show answer

Multiply by 3: \(2x - 1 > 9\), so \(2x > 10\) and \(x > 5\). Open dot at 5, shade right.

Question E6 Original

A solution of a linear inequation is every real number strictly between \(-4\) and 1, inclusive of \(-4\). Write the inequation chain and its solution set.

Show answer

Chain: \(-4 \le x < 1\). Solution set = \(\{x : x \in \mathbb{R},\; -4 \le x < 1\}\).

F. Common Mistakes

Common mistakeCorrect approach
Multiplying or dividing by a negative without reversing the inequality sign.Whenever you multiply or divide both sides by a negative number, reverse the symbol (\(\le \leftrightarrow \ge\) and < \(\leftrightarrow\) >).
Giving a finite set of solutions when \(x \in \mathbb{R}\).For \(x \in \mathbb{R}\), write the set-builder form such as \(\{x : x \in \mathbb{R},\; x > 5\}\) and show it on a number line.
Using an open dot for \(\le\) (or \(\ge\)).Use a closed (filled) dot when the endpoint is included; an open dot only for strict < or >.
Cross-multiplying or cancelling an unknown factor in an inequation.Never multiply or divide by a quantity whose sign you do not know – it may reverse the inequality.
Splitting a chain inequation but treating it as OR.A chain like \(a < bx + c \le d\) means both parts (AND); take the overlapping interval.
Stopping before dividing, leaving \(2x \ge 10\) as the final answer.Always isolate \(x\) completely: divide to get \(x \ge 5\).
Including values outside the replacement set in the solution set.Filter the solved inequality using the replacement set: for \(x \in \mathbb{W}\), keep only whole numbers that satisfy it.
Writing the solution set with wrong notation, e.g. \(\{x < 5\}\) or \((5, \infty]\) but excluding the endpoint wrongly.Use proper set-builder notation \(\{x : x \in \mathbb{R},\; x \le 5\}\); endpoint 5 included → closed, \((5, \infty)\) would wrongly exclude 5.

G. Exam Tips

Scoring tips
  • Isolate the variable exactly as in an equation; the only extra step is the sign reversal rule.
  • Always state the replacement set in your final answer – ICSE marks are awarded for it.
  • For number-line questions, draw dots first, then shade; a small open/closed dot error loses marks.
  • If the variable disappears (e.g. \(0 \ge -5\)), state whether the statement is true for all reals or false for all reals.
  • In chain inequations write \(x\) alone in the middle (e.g. \(-2 < x \le 4\)) in the final step.

H. Quick Revision Sheet – Linear Inequations

Remember
  • \(\ge, \le, >, <\) – solution is usually a set, not a single value.
  • Adding/subtracting: sign unchanged. Multiply/divide by positive: sign unchanged. Multiply/divide by negative: reverse sign.
  • Closed dot \(\bullet\) for included; open dot \(\circ\) for excluded.
  • Chain \(a < bx + c \le d\) → split and take the common part.
  • Filter the final inequality using the replacement set.

Topic 2 – Quadratic Equations

A. Learning Objectives

After studying this topic you should be able to:

  • Identify a quadratic equation in one variable and write it in the standard form \(ax^2 + bx + c = 0\).
  • Solve quadratic equations by factorisation and by the quadratic formula.
  • Use the discriminant \(b^2 - 4ac\) to determine the nature of the roots.
  • Give roots to a stated degree of accuracy (one decimal place, two, or three significant figures) as required by the question.
  • Solve word problems that reduce to quadratic equations.

B. Basic Concepts and Definitions

Quadratic equation

An equation of the form \(ax^2 + bx + c = 0\) where \(a \ne 0\). The values of \(x\) that satisfy it are called its roots (or solutions). A quadratic equation has at most two real roots.

Solving by factorisation

Express \(ax^2 + bx + c\) as a product of two linear factors. If the product is zero, then one of the factors must be zero (the zero-product rule). For example \(x^2 - 5x + 6 = (x - 2)(x - 3) = 0\) gives \(x = 2\) or \(x = 3\).

Roots of the equation \(px^2 - qx + r = 0\)

For the equation \(px^2 - qx + r = 0\) (here \(a = p\), \(b = -q\), \(c = r\)), the roots are real and equal if and only if the discriminant is zero: \[b^2 - 4ac = (-q)^2 - 4pr = q^2 - 4pr = 0 \;\Rightarrow\; q^2 = 4pr.\]

Discriminant and nature of roots

For \(ax^2 + bx + c = 0\), the discriminant is \(D = b^2 - 4ac\):

  • \(D > 0\) – two distinct real roots;
  • \(D = 0\) – real and equal roots;
  • \(D < 0\) – no real roots.

If the roots are required "correct to one decimal place" or "to 3 significant figures", use the quadratic formula and round only at the end.

C. Important Formulas

Quadratic formula
\(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
Works for any quadratic \(ax^2 + bx + c = 0\), including those that do not factorise.
Discriminant
\(D = b^2 - 4ac\)
\(D > 0\): two distinct real roots; \(D = 0\): real and equal; \(D < 0\): no real roots.
Sum and product of roots
\(\text{Sum} = -\dfrac{b}{a}, \qquad \text{Product} = \dfrac{c}{a}\)
Useful for checking answers and for framing equations from given roots.
Equation from given roots \(\alpha, \beta\)
\(x^2 - (\alpha + \beta)x + \alpha\beta = 0\)
When the leading coefficient is 1 in the standard form \(x^2 - Sx + P = 0\).

D. Step-by-Step Solved Examples

Level 1 Solving by factorisation

Example 1

Solve \(x^2 - 5x + 6 = 0\).

1
Find two numbers whose product is \(+6\) and whose sum is \(-5\): they are \(-2\) and \(-3\).
2
Factorise: \((x - 2)(x - 3) = 0\).
3
Apply the zero-product rule: \(x - 2 = 0\) or \(x - 3 = 0\).
4
Roots: \(x = 2\) or \(x = 3\).

Level 2 Quadratic formula to 3 significant figures (verified ICSE board question)

Example 2 – ICSE 2024 (Section B)

Solve the equation \(2x^2 - 10x + 5 = 0\), giving the roots correct to 3 significant figures.

1
Identify \(a = 2,\; b = -10,\; c = 5\).
2
Discriminant: \(D = (-10)^2 - 4(2)(5) = 100 - 40 = 60\).
3
Formula: \(x = \dfrac{10 \pm \sqrt{60}}{2(2)} = \dfrac{10 \pm \sqrt{60}}{4}\).
4
\(\sqrt{60} \approx 7.7460\), so \(x = \dfrac{17.7460}{4} = 4.4365\) or \(x = \dfrac{2.2540}{4} = 0.5635\).
5
Correct to 3 significant figures: \(x = 4.44\) or \(x = 0.564\).

Level 3 Quadratic formula to one decimal place (verified ICSE board question)

Example 3 – ICSE 2023 (Section A)

Solve the quadratic equation \(x^2 + 4x - 8 = 0\), correct to one decimal place.

1
Here \(a = 1,\; b = 4,\; c = -8\).
2
Discriminant: \(D = 16 + 32 = 48\).
3
Formula: \(x = \dfrac{-4 \pm \sqrt{48}}{2} = -2 \pm \sqrt{12}\), i.e. \(-2 \pm 2\sqrt{3}\).
4
\(2\sqrt{3} \approx 3.4641\), so \(x = 1.4641\) or \(x = -5.4641\).
5
Correct to one decimal place: \(x = 1.5\) or \(x = -5.5\).

E. Exam-Style Questions

Question E1 ICSE Board 2023

If 3 is a root of the quadratic equation \(x^2 - px + 3 = 0\), find the value of \(p\).

Show answer

Substitute \(x = 3\): \(9 - 3p + 3 = 0\) → \(12 - 3p = 0\) → \(p = 4\).

Question E2 ICSE Board 2024

The roots of the quadratic equation \(px^2 - qx + r = 0\) are real and equal. Show that \(q^2 = 4pr\).

Show answer

Real and equal roots require discriminant \(= 0\). Here \(a = p,\; b = -q,\; c = r\), so \(b^2 - 4ac = q^2 - 4pr = 0\), giving \(q^2 = 4pr\).

Question E3 Original

Solve \(x^2 - 8x + 15 = 0\) by factorisation.

Show answer

\((x - 3)(x - 5) = 0\), so \(x = 3\) or \(x = 5\).

Question E4 Original

Without solving, state the nature of the roots of \(2x^2 - 4x + 3 = 0\).

Show answer

\(D = (-4)^2 - 4(2)(3) = 16 - 24 = -8 < 0\). The equation has no real roots.

Question E5 Original

Solve \(x(x - 6) = 7\).

Show answer

\(x^2 - 6x - 7 = 0\) → \((x - 7)(x + 1) = 0\) → \(x = 7\) or \(x = -1\).

Question E6 Original

The product of two consecutive positive integers is 420. Find the integers.

Show answer

Let the integers be \(x\) and \(x + 1\). Then \(x(x + 1) = 420\) → \(x^2 + x - 420 = 0\) → \((x + 21)(x - 20) = 0\) → \(x = 20\) (positive). Integers are 20 and 21.

F. Common Mistakes

Common mistakeCorrect approach
Writing the quadratic formula with a wrong sign, e.g. \(x = -b \pm \sqrt{b^2 - 4ac}\).The minus in front of \(b\) comes from the formula itself: \(x = \dfrac{-b \pm \sqrt{D}}{2a}\); keep \(-b\) over the denominator.
Forgetting the denominator \(2a\) and dividing by 2 only.Put the whole numerator over \(2a\); when \(a \ne 1\), the denominator is not 2.
Rounding intermediate values while using the formula.Keep the exact surd form as long as possible; round only the final answer to the asked accuracy.
Cancelling a factor of \(x\) from both sides (e.g. \(x^2 = x \Rightarrow x = 1\)).Bring all terms to one side and factorise: \(x^2 - x = 0 \Rightarrow x(x - 1) = 0 \Rightarrow x = 0\) or \(x = 1\).
Discarding a negative root even when nothing in the question rules it out.Discard a root only if it is impossible in the context (e.g. a negative length or time).
Confusing the roles of \(a, b, c\) when the equation is written as \(px^2 - qx + r = 0\).First write the equation in standard form \(ax^2 + bx + c = 0\); then \(b = -q\), not \(q\).
Saying "no solution" for a negative discriminant in a word problem.State "no real roots" – the equation still has complex roots, but for the ICSE syllabus you conclude no real solution.
Not checking roots are the answer the question wanted (e.g. giving both roots when only positive length is needed).Re-read the question; for applied problems, write the meaningful value with its units.

G. Exam Tips

Scoring tips
  • Try factorisation mentally for simple equations; if the middle term is awkward, go straight to the formula.
  • Show \(a = \ldots,\; b = \ldots,\; c = \ldots\) and the discriminant before the answer – partial marks are awarded.
  • When roots are asked "correct to one decimal place" or "to 3 significant figures", write the exact surd form first and round at the end.
  • For nature-of-roots questions, quote the rule (\(D > 0\), \(D = 0\), \(D < 0\)) after computing \(D\).
  • Verify by substituting the roots back into the original equation.

H. Quick Revision Sheet – Quadratic Equations

Remember
  • Standard form: \(ax^2 + bx + c = 0\), \(a \ne 0\).
  • Factorise → zero-product rule; otherwise quadratic formula \(x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\).
  • \(D = b^2 - 4ac\): >0 two roots, =0 equal roots, <0 no real roots.
  • Sum of roots \(= -b/a\); product of roots \(= c/a\).
  • Round to the asked accuracy only at the final step.

Topic 3 – Ratio and Proportion

A. Learning Objectives

After studying this topic you should be able to:

  • Express a ratio and write equivalent ratios in simplest form.
  • Check whether four quantities are in proportion and find the missing term.
  • Find the mean proportional, third proportional and fourth proportional.
  • Apply the properties \(a : b = c : d \Leftrightarrow ad = bc\).
  • Apply componendo and dividendo to solve problems and equations.

B. Basic Concepts and Definitions

Ratio

The ratio \(a : b\) is the comparison of two quantities of the same kind, written as a fraction \(\frac{a}{b}\) in its lowest terms. Example: the ratio 12 : 8 equals 3 : 2.

Proportion

Four numbers \(a, b, c, d\) are in proportion when \(a : b = c : d\), written \(a : b :: c : d\). The key property is the cross product:

\[a : b = c : d \quad \Leftrightarrow \quad ad = bc.\]

Mean, third and fourth proportional
  • Mean proportional between \(a\) and \(b\): a number \(x\) such that \(a : x = x : b\), i.e. \(x^2 = ab\), so \(x = \sqrt{ab}\).
  • Third proportional to \(a\) and \(b\): a number \(x\) such that \(a : b = b : x\), so \(x = \frac{b^2}{a}\).
  • Fourth proportional to \(a, b, c\): a number \(x\) such that \(a : b = c : x\), so \(x = \frac{bc}{a}\).

If \(a, b, c\) are in continued proportion, then \(b^2 = ac\).

Componendo and dividendo

If \(\dfrac{a}{b} = \dfrac{c}{d}\), then \(\dfrac{a + b}{a - b} = \dfrac{c + d}{c - d}\). This rule lets you "compose" and "divide" numerators and denominators together and is very useful for solving equations with surds.

C. Important Formulas

Cross-product property
\(a : b = c : d \;\Leftrightarrow\; ad = bc\)
The product of the extremes equals the product of the means.
Mean proportional
\(\text{Mean proportional of } a, b = \sqrt{ab}\)
Between 4 and 9: \(\sqrt{4 \times 9} = 6\).
Third / fourth proportional
\(\text{3rd proportional to } a, b : \dfrac{b^2}{a} \qquad \text{4th proportional to } a, b, c : \dfrac{bc}{a}\)
From \(a : b = b : x\) and \(a : b = c : x\) respectively.
Componendo and dividendo
\(\dfrac{a}{b} = \dfrac{c}{d} \;\Rightarrow\; \dfrac{a + b}{a - b} = \dfrac{c + d}{c - d}\)
Add and subtract the numerator and denominator of each side.

D. Step-by-Step Solved Examples

Level 1 Mean proportional (verified ICSE board question)

Example 1 – ICSE 2023 (Section A)

Find the mean proportional between 4 and 9.

1
Mean proportional \(x\) satisfies \(4 : x = x : 9\).
2
So \(x^2 = 4 \times 9 = 36\).
3
\(x = \sqrt{36} = 6\).

Level 2 Ratio from a cube ratio (verified ICSE board question)

Example 2 – ICSE 2024 (Section B)

If \(\dfrac{(a + b)^3}{(a - b)^3} = \dfrac{64}{27}\), find the ratio \(a : b\).

1
Take the cube root of both sides: \(\dfrac{a + b}{a - b} = \dfrac{\sqrt[3]{64}}{\sqrt[3]{27}} = \dfrac{4}{3}\).
2
Cross-multiply: \(3(a + b) = 4(a - b)\).
3
Expand: \(3a + 3b = 4a - 4b\), so \(7b = a\).
4
Therefore \(a : b = 7 : 1\).

Level 3 Componendo and dividendo (verified ICSE board question)

Example 3 – ICSE 2023 (Section B)

Using componendo and dividendo, solve for \(x\): \[\frac{\sqrt{2x + 2} + \sqrt{2x - 1}}{\sqrt{2x + 2} - \sqrt{2x - 1}} = 3.\]

1
Let \(A = \sqrt{2x + 2}\) and \(B = \sqrt{2x - 1}\). Given \(\dfrac{A + B}{A - B} = \dfrac{3}{1}\).
2
Apply componendo and dividendo: \(\dfrac{(A + B) + (A - B)}{(A + B) - (A - B)} = \dfrac{3 + 1}{3 - 1}\).
3
Simplify: \(\dfrac{2A}{2B} = \dfrac{4}{2}\), so \(\dfrac{A}{B} = 2\).
4
Thus \(\sqrt{2x + 2} = 2\sqrt{2x - 1}\). Squaring: \(2x + 2 = 4(2x - 1)\).
5
Solve: \(2x + 2 = 8x - 4\), so \(6 = 6x\), giving \(x = 1\).

E. Exam-Style Questions

Question E1 Original

Find the fourth proportional to 5, 8 and 15.

Show answer

\(5 : 8 = 15 : x\) → \(5x = 120\) → \(x = 24\).

Question E2 Original

If \(a : b = 3 : 4\) and \(b : c = 2 : 5\), find \(a : c\).

Show answer

Make \(b\) the same in both ratios: \(b : c = 2 : 5 = 4 : 10\). So \(a : b : c = 3 : 4 : 10\), hence \(a : c = 3 : 10\).

Question E3 Original

Find the mean proportional between 2 and 18.

Show answer

\(x^2 = 2 \times 18 = 36\), so \(x = 6\).

Question E4 Original

If 2, \(x\) and 18 are in continued proportion, find \(x\).

Show answer

Continued proportion: \(2 : x = x : 18\) → \(x^2 = 36\) → \(x = 6\).

Question E5 Original

If \(\dfrac{x}{y} = \dfrac{7}{9}\), find the value of \(\dfrac{x + y}{x - y}\).

Show answer

By componendo and dividendo: \(\dfrac{x + y}{x - y} = \dfrac{7 + 9}{7 - 9} = \dfrac{16}{-2} = -8\).

Question E6 Original

Find the third proportional to 4 and 8.

Show answer

\(4 : 8 = 8 : x\) → \(4x = 64\) → \(x = 16\).

F. Common Mistakes

Common mistakeCorrect approach
Comparing quantities of different units in a ratio.Convert to the same unit first (e.g. 1 kg : 500 g becomes 1000 : 500 = 2 : 1).
Taking only the positive or negative mean proportional without context.Mean proportional \(= \pm\sqrt{ab}\) in general; for lengths/positive quantities take the positive value.
Writing \(a : b = c : d\) as \(ac = bd\).The correct identity is \(ad = bc\) (extremes × extremes = means × means).
Confusing third, fourth and mean proportional definitions.Mean: \(a : x = x : b\). Third: \(a : b = b : x\). Fourth: \(a : b = c : x\). Memorise the three patterns.
In componendo and dividendo, applying it when the ratio is not in the form \(\frac{a}{b} = \frac{c}{d}\).The rule applies only to equal ratios; if the RHS is a plain number \(k\), write it as \(\frac{k}{1}\) first.
Forgetting to reduce a ratio to lowest terms.Always write the final ratio in simplest form, e.g. 12 : 8 = 3 : 2.
Assuming \(a : b = 3 : 4\) means \(a = 3\) and \(b = 4\).Write \(a = 3k, b = 4k\); then apply the other given condition to find \(k\).
Squaring a surd equation and not checking for extraneous roots.After squaring, substitute the value back into the original equation and discard any root that does not satisfy it.

G. Exam Tips

Scoring tips
  • State the cross product step \(ad = bc\) explicitly – it is a mark-bearing step.
  • For "continued proportion", always write \(a : x = x : b\) before squaring.
  • With componendo and dividendo, show the two fractions \((\text{sum}, \text{difference})\) explicitly.
  • Check whether the answer needs to be positive (lengths, ages, money).
  • In ratio problems introduce \(k\): \(a : b = p : q \Rightarrow a = pk, b = qk\).

H. Quick Revision Sheet – Ratio and Proportion

Remember
  • \(a : b = c : d \Leftrightarrow ad = bc\).
  • Mean proportional \(= \sqrt{ab}\); third \(= \frac{b^2}{a}\); fourth \(= \frac{bc}{a}\).
  • Continued proportion: \(b^2 = ac\).
  • Componendo and dividendo: \(\frac{a}{b} = \frac{c}{d} \Rightarrow \frac{a+b}{a-b} = \frac{c+d}{c-d}\).
  • Use \(k\) for ratios: \(a : b = p : q \Rightarrow a = pk, b = qk\).

Topic 4 – Factorisation of Polynomials

A. Learning Objectives

After studying this topic you should be able to:

  • State and apply the remainder theorem to find remainders without long division.
  • State and apply the factor theorem to test whether a linear expression is a factor.
  • Find an unknown coefficient when a given linear expression is a factor.
  • Factorise a cubic polynomial completely using the factor theorem and polynomial division.

B. Basic Concepts and Definitions

Remainder theorem

If a polynomial \(P(x)\) is divided by \(x - a\), the remainder is \(P(a)\). You never need to divide: just substitute \(x = a\) into the polynomial.

Factor theorem

\(x - a\) is a factor of \(P(x)\) if and only if \(P(a) = 0\). This follows from the remainder theorem when the remainder is zero.

Finding an unknown coefficient

If \(x - a\) is a factor of a polynomial \(P(x)\) that contains an unknown coefficient \(k\), substitute \(x = a\), set \(P(a) = 0\), and solve the resulting linear equation for \(k\).

Factorising a cubic completely

Test small integer values (\(x = \pm 1, \pm 2, \pm 3, \ldots\)) to find one linear factor. Divide to obtain a quadratic, then factorise the quadratic (or use the quadratic formula) to get all three factors.

C. Important Formulas

Remainder theorem
\(\text{Remainder when } P(x) \text{ is divided by } x - a = P(a)\)
For divisor \(ax + b\), use \(x = -\frac{b}{a}\) and the remainder is \(P\big(-\frac{b}{a}\big)\).
Factor theorem
\(x - a \text{ is a factor of } P(x) \;\Leftrightarrow\; P(a) = 0\)
The familiar test: substituting the root must give zero.
Cubic factorisation pattern
\(P(x) = (x - a)(px^2 + qx + r)\)
Once one linear factor is found, divide to get the quadratic factor and continue.

Topic 5 – Matrices

A. Learning Objectives

After studying this topic you should be able to:

  • State the order of a matrix and write individual elements.
  • Use matrix equality to find unknown elements.
  • Add, subtract and multiply a matrix by a scalar.
  • Multiply two matrices where the orders allow it.
  • Use the identity matrix \(I\) and the algebra \(A(B + C) = AB + AC\).

B. Basic Concepts and Definitions

Matrix and its order

A matrix is a rectangular arrangement of numbers in rows and columns. Its order is \(m \times n\) (read "\(m\) by \(n\)"), where \(m\) = number of rows and \(n\) = number of columns. A matrix with one column is a column matrix; with one row, a row matrix.

Equality of matrices

Two matrices are equal when they have the same order and every corresponding element is equal. This allows you to compare entries and solve for unknowns. Note that \(\begin{bmatrix}1 & 2\end{bmatrix} \ne \begin{bmatrix}1 \\ 2\end{bmatrix}\) because the orders differ.

Addition, subtraction and scalar multiplication

Matrices of the same order are added (or subtracted) element by element. In scalar multiplication, every element is multiplied by the scalar: \(k\begin{bmatrix}a & b \\ c & d\end{bmatrix} = \begin{bmatrix}ka & kb \\ kc & kd\end{bmatrix}\).

Multiplication of matrices

\(AB\) exists only when the number of columns of \(A\) equals the number of rows of \(B\). If \(A\) is \(m \times q\) and \(B\) is \(q \times n\), then \(AB\) is \(m \times n\), with each entry the "row × column" dot product. Matrix multiplication is not commutative in general.

Identity matrix \(I\)

The identity matrix is a square matrix with 1 on the main diagonal and 0 elsewhere, e.g. \(I = \begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}\). For any compatible matrix \(A\), \(AI = IA = A\).

C. Important Formulas

Element of a product
\((AB)_{ij} = \sum_k a_{ik}b_{kj}\)
Entry in row \(i\), column \(j\) of \(AB\) = sum of products of row \(i\) of \(A\) with column \(j\) of \(B\).
Compatibility rule
\((m \times q) \cdot (q \times n) = (m \times n)\)
Inner dimensions must match; the result takes the outer dimensions.
Identity property
\(AI = IA = A, \qquad I = \begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}\)
Multiplying by the identity leaves a matrix unchanged.
Distributive laws
\(A(B + C) = AB + AC, \qquad (A + B)C = AC + BC\)
Same shape rules as real numbers, but order matters: \(AB \ne BA\) usually.

1

2

3
Hence \(x = 1\) and \(y = -2\).

Example 2 – ICSE 2024 (Section A)

1

Given \(A = \begin{bmatrix}1 & 3 \\ 2 & 4\end{bmatrix}\), \(B = \begin{bmatrix}1 & 2 \\ 2 & 4\end{bmatrix}\), \(C = \begin{bmatrix}4 & 1 \\ 1 & 5\end{bmatrix}\) and \(I = \begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}\), find \(A(B + C) - 14I\).

Add: \(B + C = \begin{bmatrix}5 & 3 \\ 3 & 9\end{bmatrix}\).

Topic 6 – Arithmetic Progression (AP)

A. Learning Objectives

After studying this topic you should be able to:

  • Recognise an arithmetic progression and find its common difference.
  • Write the nth term \(T_n = a + (n-1)d\).
  • Find the first term, common difference or term number when other information is given.
  • Use the sum of n terms formula, including the last-term form \(S_n = \frac{n}{2}(a + l)\).
  • Solve problems that give two terms and require \(a\), \(d\) and a sum.

B. Basic Concepts and Definitions

Arithmetic progression

A sequence in which each term after the first differs from the previous term by a fixed number called the common difference \(d\). Example: \(15, 30, 45, 60, \ldots\) is an AP with \(a = 15\) and \(d = 15\).

nth term

\(T_n = a + (n-1)d\), where \(a\) is the first term and \(d\) is the common difference. To find a middle term given two other terms, set up equations in \(a\) and \(d\).

Sum of the first n terms

\(S_n = \dfrac{n}{2}\big[2a + (n-1)d\big]\), or \(S_n = \dfrac{n}{2}(a + l)\) where \(l = T_n\) is the last term. Both give the same total; use the second form when the last term is known.

Three consecutive terms

If \(a, b, c\) are in AP, then \(2b = a + c\) (the middle term is the average of its neighbours). This is a quick checking tool.

C. Important Formulas

nth term
\(T_n = a + (n-1)d\)
\(a\) = first term, \(d\) = common difference, \(n\) = term number.
Sum of n terms
\(S_n = \dfrac{n}{2}\big[2a + (n-1)d\big]\)
Use when \(a\) and \(d\) are known.
Sum using the last term \(l\)
\(S_n = \dfrac{n}{2}(a + l)\)
Useful when the last term is given or easy to find.
Triplets in AP
\(a, b, c \text{ in AP } \Rightarrow 2b = a + c\)
Middle = average of neighbours.

D. Step-by-Step Solved Examples

Level 1 Term directly from the nth term (verified ICSE board question)

Example 1 – ICSE 2023 (Section A)

The nth term of an AP is \(2n + 5\). Find its 10th term (and the common difference).

1
10th term: put \(n = 10\). \(T_{10} = 2(10) + 5 = 25\).
2
First term: \(T_1 = 2(1) + 5 = 7\).
3
Common difference: \(T_2 - T_1 = (4 + 5) - 7 = 9 - 7 = 2\).

Level 2 First term and common difference from two terms (verified ICSE board question)

Example 2 – ICSE 2023 (Section B)

The 5th and 9th terms of an AP are 4 and \(-12\). Find (a) the first term, (b) the common difference, (c) the sum of the first 16 terms.

1
Set up: \(a + 4d = 4\) and \(a + 8d = -12\).
2
Subtract the first from the second: \(4d = -16\), so \(d = -4\).
3
Back-substitute: \(a + 4(-4) = 4\) → \(a = 20\).
4
Sum: \(S_{16} = \frac{16}{2}\big[2(20) + 15(-4)\big] = 8(40 - 60) = -160\).

Level 3 Term number and sum (verified ICSE board question)

Example 3 – ICSE 2023 (Section B)

Which term of the AP \(15, 30, 45, 60, \ldots\) is 300? Hence find the sum of all the terms from the first term up to this term.

1
Here \(a = 15\), \(d = 15\). \(T_n = 15 + (n-1)15 = 15n\).
2
Set \(15n = 300\), so \(n = 20\). 300 is the 20th term.
3
Sum: \(S_{20} = \frac{20}{2}(15 + 300) = 10 \times 315 = 3150\).

Topic 7 – Geometric Progression (GP)

A. Learning Objectives

After studying this topic you should be able to:

  • Recognise a geometric progression and find its common ratio \(r\).
  • Write the nth term \(T_n = ar^{n-1}\).
  • Use the sum of n terms formula for a GP.
  • Find a term number from a given term value (using powers).
  • Distinguish AP situations from GP situations in problems.

B. Basic Concepts and Definitions

Geometric progression

A sequence in which each term after the first is obtained by multiplying the previous term by a fixed number called the common ratio \(r\). Example: \(15, 30, 60, 120, \ldots\) is a GP with \(a = 15\), \(r = 2\).

nth term

\(T_n = ar^{n-1}\). The common ratio \(r = \frac{T_{k+1}}{T_k}\). A ratio \(r\) may be negative or fractional (e.g. \(1, -\frac12, \frac14, \ldots\)).

Sum of the first n terms

\(S_n = \dfrac{a(r^n - 1)}{r - 1}\). For \(|r| < 1\) the same formula is often written \(S_n = \dfrac{a(1 - r^n)}{1 - r}\), which keeps the denominator positive. Both are identical.

Three consecutive terms

\(a, b, c\) are in GP if and only if \(b^2 = ac\) (the middle term squared equals the product of its neighbours).

C. Important Formulas

nth term
\(T_n = ar^{n-1}\)
\(a\) = first term, \(r\) = common ratio.
Sum of n terms
\(S_n = \dfrac{a(r^n - 1)}{r - 1}\)
For \(r > 1\) this form is convenient; for \(|r| < 1\) use \(\dfrac{a(1 - r^n)}{1 - r}\).
Common ratio
\(r = \dfrac{T_{k+1}}{T_k}\)
Later term divided by the earlier term.
Triplets in GP
\(a, b, c \text{ in GP } \Rightarrow b^2 = ac\)
Use this to test or find a missing middle term.

D. Step-by-Step Solved Examples

Level 1 Finding a specific term

Example 1

1
First term \(a = 3\); common ratio \(r = 6 \div 3 = 2\).
2
\(T_5 = ar^{4} = 3 \times 2^4 = 3 \times 16 = 48\).

Level 3 Sum with a fractional ratio

Example 3 (Original)

Find the sum of the first 6 terms of the GP \(1, \frac12, \frac14, \ldots\).

1
\(a = 1\), \(r = \frac12\), \(n = 6\).
2
Use the \(|r| < 1\) form: \(S_6 = \dfrac{1\left(1 - \left(\frac12\right)^6\right)}{1 - \frac12}\).
3
\(\left(\frac12\right)^6 = \frac{1}{64}\), so \(S_6 = \dfrac{1 - \frac{1}{64}}{\frac12} = \dfrac{63}{64} \times 2 = \dfrac{63}{32}\).

E. Exam-Style Questions

Question E1 Original

Which term of the GP \(2, 4, 8, \ldots\) is 512?

Show answer

\(a = 2\), \(r = 2\). \(T_n = 2 \times 2^{n-1} = 2^n = 512 = 2^9\), so \(n = 9\).

Question E2 Original

Find the 6th term of the GP \(81, 27, 9, \ldots\).

Show answer

\(a = 81\), \(r = \frac13\). \(T_6 = 81 \times (\frac13)^5 = 81 \times \frac{1}{243} = \frac13\).

Question E3 Original

Find the sum \(1 + 2 + 4 + 8 + 16\).

Show answer

\(a=1\), \(r=2\), \(n=5\): \(S = \frac{1(2^5 - 1)}{2 - 1} = \frac{32 - 1}{1} = 31\).

Question E4 Original

Show that \(5, 10, 20\) are in GP, and write the common ratio.

Show answer

\(b^2 = 10^2 = 100\) and \(a \cdot c = 5 \cdot 20 = 100\); since \(b^2 = ac\), they are in GP with \(r = 2\).

Question E5 Original

The product of the first three terms of a GP with \(a = 2\) and \(r = 3\) equals the product of which three numbers?

Show answer

Terms are \(2, 6, 18\); product \(= 2 \times 6 \times 18 = 216\).

Question E6 Original

Find the sum of the GP \(3 + 6 + 12 + \cdots + 192\).

Show answer

\(a = 3\), \(r = 2\). Last term \(192 = 3 \times 2^{n-1}\) → \(2^{n-1} = 64\) → \(n = 7\). \(S_7 = \frac{3(2^7 - 1)}{2 - 1} = 3 \times 127 = 381\).

F. Common Mistakes

Common mistakeCorrect approach
Using an AP formula for a GP problem (adding instead of multiplying).AP adds a common difference; GP multiplies by a common ratio. Decide first which one is being described.
Writing the exponent as \(n\) instead of \(n - 1\) in \(T_n\).The first term is \(ar^0\), so the \(n\)th term uses \(n - 1\) multiplications by \(r\).
Computing \(r\) backwards: \(r = \frac{T_k}{T_{k+1}}\).\(r = \frac{T_{k+1}}{T_k}\), i.e. later term divided by earlier term.
Using \(S_n = \frac{a(r^n - 1)}{r - 1}\) with a fractional \(r < 1\) and getting a wrong sign.For \(|r| < 1\) use \(\frac{a(1 - r^n)}{1 - r}\) so the denominator is positive.
Forgetting the term \(a\) multiplies the whole bracket in \(S_n\).\(S_n = a \cdot \frac{r^n - 1}{r - 1}\); the leading \(a\) multiplies the entire fraction.
Treating negative \(r\) with an even power carelessly (sign errors).With \(r = -2\), powers alternate sign: \(r^3 = -8\), \(r^4 = 16\). Decide the sign first.
Not recognising \(2^n = 64\) for \(n = 6\) and guessing.Learn powers of 2 up to \(2^{10}\) and other common powers; then the term-number step is instant.
Misreading \(1 + \frac12 + \frac14 + \cdots\) as an AP.The ratio \(\frac12\) (multiply) means it is a GP with \(|r| < 1\) – use the fraction form of the sum.

G. Exam Tips

Scoring tips
  • Write \(a = \ldots,\; r = \ldots\) at the top; they are the first two marks.
  • For the sum, show \(S_n = a\frac{r^n - 1}{r - 1}\) and substitute in one neat line.
  • When a term value is given, work with powers: \(T_n = 512 \Rightarrow 2^{n-1} \times 2 = 2^n\).
  • For \(|r| < 1\) choose the form with \(1 - r\) in the denominator to avoid negative signs.
  • Practise the powers \(2^1\) to \(2^{10}\) and \(3^1\) to \(3^5\) for fast term-count work.

H. Quick Revision Sheet – Geometric Progression

Remember
  • \(r = \frac{T_{k+1}}{T_k}\); GP multiplies by \(r\), AP adds by \(d\).
  • \(T_n = ar^{n-1}\).
  • \(S_n = \frac{a(r^n - 1)}{r - 1}\) (use \(\frac{a(1 - r^n)}{1 - r}\) for \(|r| < 1\)).
  • \(a, b, c\) in GP \(\Rightarrow b^2 = ac\).
  • Match powers to find the term number \(n\).
