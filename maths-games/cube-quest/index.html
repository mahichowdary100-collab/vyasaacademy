How to Play

  1. 3D Cube Builder — pick a challenge, then tap cells in each layer to build the cube. Rotate the model with ← → or the buttons. Completion is checked against the real shape (n³ unit cubes), not just a click.
  2. Perfect Cube Matching — select two cards that belong together (for example 8 and 2³). Tap the first card, then its partner. Correct pairs lock in green.
  3. Timed Cube Challenge — choose 30, 60 or 90 seconds. Answer with the number keys 1–4 or by typing and pressing Enter. Accuracy is worth more than speed.
  4. Escape Room — each chamber has three locks. Use a hint if you are stuck (a small bonus is forfeited) and read the explanation after a wrong attempt.
  5. Beat the Cube Bot — you and the bot answer the same question each round. First to fill the score bar wins. Hints, streaks and difficulty changes are shown in plain words.

Press Esc to return home. Progress is stored privately on this device.
